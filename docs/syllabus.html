04 / 项目与交付

三阶段的交付要求

第3周起的工作在同一 git 仓库演进。个人课程仓库通过 GitHub 邀请发放；一般作业按截止时仓库快照评分，黑客松在 PrairieLearn 提交。

APPLY / 18%

引导练习与结对编程工具

第1–2周共16个 Aider 练习，涉及任务管理 CLI 和基于同一数据的 Web 前端；9月11日截止。第3–6周实现结对编程工具：7项功能、YAML配置；10月6日截止。项目负担原文标记为重新设计中。

评分细目（项目内分值）

规格与设计：50分

  • 需求10；架构/接口10；Aider分步实现计划10。
  • 图示10：组件图4、时序图3、生命周期图3。
  • 先写规格后写代码5；说明变更与原因5。

实现与测试：50分

  • 功能正确性25；自定义测试9；失败路径测试8。
  • 端到端运行与现场证据5；操作说明3。

交付包含系统/增量规格、三种图、学生编写的测试、YAML示例、开发与运行说明、会话记录、AI_LOG.md、设计与实现对照。模型披露与证据索引是核验依据，不单独计分。测试按能否发现合理缺陷计分；正确揭示失败的测试仍可获得测试分。同一缺陷不跨其他合格产物重复扣分。

ANALYZE / 22.5%

Agent v0

10月6日发布，第7周末截止；预计3周共22–27小时。工具层需支持读、写、执行，通过真实函数调用接入；危险操作先人工审批，再加入规则审批和决策日志。实现6个停止条件、自主循环及评测套件。

  • 验收任务随规格公开，可在提交前持续调优。
  • 至少8个评测任务，每个至少运行3次，报告成功率。
  • 提供失败分析报告，说明仍无法完成的任务。
  • 第7周黑客松包含无人值守验收。

CREATE / 49.5%

知识库、设计技能与可部署助手

第8–15周。构建可 ingest / query / lint 的 Markdown 知识库；实现设计优先技能；加固权限、抗注入、上下文、会话及回归检查；最后接入 Web服务与至少一个终端以外的渠道。

  • 每阶段通过可计分的基线验收。
  • 第14–15周加入自选渠道，以及第7周失败分析中提出的一项能力。
  • 期末交付格式及细分比例待课程公告；全部为个人项目。

07 / 课程政策

提交、出勤与协作规则

学术诚信与 AI 使用

  • 必须使用 AI，并理解、能解释提交的每行代码；规格、图、实现和测试均遵守阶段模型/工具规则。
  • 记录工具、模型和提示词；不得复制其他学生的代码、提示词或报告；引用往届或外部成果须注明来源。
  • 实验验收和黑客松现场验证理解；违规按工程学院荣誉准则处理。

出勤

讲座、实验、黑客松均为必参加环节。讲座与实验使用 Poll Everywhere；实验按任务说明完成。Lab01、Lab02支持项目，不另设项目分提交。未经事先批准缺席实验的验收，FAQ说明该次验收为零分。

迟交与延期

  • 无可自由使用的迟交天数，也无重做期。
  • 项目每迟交一个自然日扣10%，最多接受3天，超过3天不计分。
  • 按截止时仓库快照评分；黑客松在现场通过PrairieLearn提交。
  • 有证明的紧急情况逐案考虑延期，须在截止前联系团队。

协作

全部工作独立完成。可讨论概念、共同排查问题，不得共享提交用的代码、提示词或报告。

无障碍支持

请联系 Services for Students with Disabilities（SSD），并在开学前两周内向教师提供支持信；黑客松特殊安排见上文。

学生支持

原站政策页列有 Counseling and Psychological Services（CAPS）与 Dean of Students Office 等支持资源。联系方式请直接核对 官方课程政策与学生支持资源。

08 / 工具与费用

配置要求与模型政策

环境

  • macOS、Linux或Windows+WSL笔记本；不要求独立GPU。
  • 大纲要求Python 3.12、git、GitHub账号。FAQ另写Python 3.11+，存在原文差异；建议按大纲并向团队核实。
  • Ollama或llama.cpp提供模型服务；Aider用于初期工具使用。第1周配置实验提供现场帮助，第2周另有监督配置窗口。
  • 不要求付费订阅；可选托管服务的凭证依服务而异，放在git之外。

Stage 1 模型限制

允许 qwen3.5:4b 与 qwen3.5:9b，推荐9B；现场监督环节还可使用课程宣布的模型。同一限制覆盖规格起草与审查、图、说明、代码、测试和辅助模型；其他模型须有正式政策修订。

允许模型可部署在实现作业所需 OpenAI-compatible Chat Completions 合约的端点上。YAML应配置API base、model ID、凭证变量名、预算、超时和temperature；应用中不硬编码Ollama专用API或主机名。换服务商不意味着允许换模型。

费用

除可运行小模型的机器外，无必购教材、必需LLM支出。CAEN机房是免费硬件替代方案；需要支持请第一周告知团队。黑客松模型端点由课程提供。
