01 / 课程定位

从使用工具，到理解系统

面向谁

先修 EECS 281 和 EECS 201，或具有高阶计算机课程资格（ULCS），或获得教师许可。

学习方式

28次讲座、13次实验、3次晚间黑客松。项目均独立完成，使用 AI 是课程要求。

02 / 三个阶段

一个项目，持续演进

01

第1–3周 · 项目延续至第6周

应用 / Apply

Aider、16个引导练习、结对编程工具。L01–L06；项目截止：10月6日（周二）。

18%
02

第4–7周

分析 / Analyze

直接使用 LLM API，自建工具调用、审批、智能体循环与评测。L07–L14；Agent v0 截止：第7周末。

22.5%
03

第8–15周

创造 / Create

知识库、设计技能、权限与上下文加固、会话记忆、Web服务与部署。L15–L28；展示：12月10日。

49.5%

另有 10% 平时管理成绩。三阶段分别占总成绩的 18%、22.5%、49.5%；详情见教学大纲。

03 / 学习目标

你将练习的核心能力

  • 利用上下文、模型、提示词三个维度定位编程智能体的问题。
  • 设计并实现结对编程工具，编写规格、架构图与测试。
  • 实现工具调用、审批层、停止条件及自主运行循环。
  • 用任务集、成功率、成本和延迟评估智能体，建立回归检查。
  • 为助手接入知识库、持久记忆、设计方法、Web服务和终端之外的交互渠道。

04 / 工具与成本

本地模型优先

工具包括 Aider、Ollama / llama.cpp、Python、git / GitHub、pytest、LLM API 与 PrairieLearn。课程无必购教材、模型 API 或编程助手订阅；硬件不足可向课程团队咨询 CAEN 机房。
